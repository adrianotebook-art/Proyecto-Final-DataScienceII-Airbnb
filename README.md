# Proyecto Final de Data Science

## Predicción del precio de alojamientos Airbnb mediante Machine Learning

### Descripción
Este proyecto tiene como objetivo analizar los factores que influyen en el precio de los alojamientos publicados en Airbnb para la ciudad de Nueva York y desarrollar un modelo de Machine Learning capaz de estimar dicho precio.

Para ello se utilizaron técnicas de limpieza de datos, análisis exploratorio (EDA), ingeniería de atributos, entrenamiento de modelos supervisados y optimización de hiperparámetros.

## Objetivos

- Analizar el comportamiento de los precios de los alojamientos.
- Identificar los factores que más influyen en el precio.
- Construir modelos predictivos de regresión.
- Comparar distintos algoritmos de Machine Learning.
- Seleccionar el modelo con mejor desempeño.

## Dataset
**Nombre:** New York Airbnb Open Data
**Registros:** 48.895
**Variables:** 16

Además, se integró información obtenida desde la API pública Open-Meteo para demostrar la incorporación de datos provenientes de múltiples fuentes.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- SHAP
- Google Colab

## Modelos entrenados
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## Resultados
El modelo **XGBoost** obtuvo el mejor desempeño entre los modelos evaluados.

**Métricas obtenidas**
- R² = 0.320
- MAE = 56.67
- RMSE = 127.60
